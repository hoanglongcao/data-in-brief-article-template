# Data in Brief - Overleaf template

This is the unofficial Data in Brief article template in Overleaf.

> **Important:** You must use `lualatex` or `xelatex` to compile this project. Other compilers like `pdflatex` may not work correctly.

[Open in Overleaf](https://www.overleaf.com/read/zpfnzsqjpdyb#b8967e)

## 📄 Submission Workflow

1. Comment out `\usepackage{lineno}`
2. Compile and download the PDF.
3. Convert the PDF to Word.
4. Enable line numbering in Word.
5. Correct any formatting issues.
